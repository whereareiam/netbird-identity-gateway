# NetBird Identity Gateway 1.0.0

An identity-only OIDC source for Authentik. NetBird proves an immutable principal;
Authentik owns users, account status, application access and entitlements.
Applications retain their Authentik issuers.

## Container

`registry.whereareiam.me/images/whereareiam/netbird-identity-gateway:1.0.0`

## Included

- Separate proxy-only authorization and Authentik backchannel listeners.
- Confidential-client authorization-code flow with mandatory S256 PKCE,
  short-lived single-use codes, bounded storage, RS256 tokens and UserInfo.
- Distinct access-token and ID-token purposes; identity assertions contain no
  application roles, groups or profile claims.
- Explicit principal allowlists or trusted-account mode with the included
  Authentik immutable identity auto-link mapping.
- Existing-user linking through the pinned NetBird account/Authentik connector,
  rejecting unknown, disabled, machine, foreign and conflicting identities.

## Deployment requirements

Enforce network isolation between the two listeners, use authenticated private
transport for Authentik's backchannel, and mount a stable signing key and client
secret. Use the verified immutable-principal NetBird proxy extension; the display
name/email header alone is not an identity credential.

Run one gateway replica: authorization codes are held in process memory. Pending
logins must be retried after a restart. Existing application session/token
revocation is owned by Authentik and the applications.

The compatible NetBird proxy extension remains based on upstream v0.77.1 and is
versioned/deployed separately from this gateway release.

## Migration from the early broker prototype

Browser fallback, gateway sessions, forward-auth, automatic user creation and
application-entitlement emission are not supported. Strict configuration parsing
rejects obsolete broker settings. Use the README's Authentik-source configuration.
